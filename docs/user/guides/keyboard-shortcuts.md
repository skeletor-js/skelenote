# Keyboard Shortcuts

Skelenote is designed for keyboard-first navigation. This guide covers all available shortcuts.

**Tip:** Press `Cmd+?` (macOS) or `Ctrl+?` (Windows/Linux) anytime to see the shortcuts overlay.

## Platform Note

Throughout this guide, `Cmd` refers to:

- **macOS:** Command key
- **Windows/Linux:** Ctrl key

---

## Global

| Shortcut | Action |
|----------|--------|
| `Cmd+K` | Open Omnibar |
| `Cmd+?` | Show keyboard shortcuts |
| `Cmd+Shift+F` | Global search |
| `Cmd+,` | Open settings |

---

## Navigation

| Shortcut | Action |
|----------|--------|
| `Cmd+[` | Navigate back |
| `Cmd+]` | Navigate forward |
| `Arrow Up/Down` | Move selection |
| `Tab` | Next focusable element |
| `Shift+Tab` | Previous focusable element |
| `Enter` | Open / Confirm |
| `Esc` | Close / Cancel |

## Omnibar

The Omnibar (`Cmd+K`) provides quick access to all actions:

- Start typing to filter commands
- Use arrow keys to navigate results
- Press `Enter` to execute
- Press `Esc` to dismiss

### Quick Actions in Palette

- Type `>` to filter to commands only
- Type `@` to search for objects to link
- Type object names directly to navigate

---

## Split View

Skelenote supports split-pane viewing:

1. Click an object link while holding `Cmd` to open in split
2. Use `Cmd+\` to close the split
3. Use `Cmd+Shift+\` to swap pane contents

---

## Tips

### Keyboard Navigation in Lists

When focused on a list (Inbox, Tasks, etc.):

- `Arrow Up/Down` moves selection
- `Enter` opens selected item
- `Space` can toggle task completion

### Focus Flow

- `Tab` moves through interactive elements
- `Shift+Tab` moves backward
- `Esc` dismisses modals and returns focus

### Editor Shortcuts

The BlockNote editor supports standard formatting:

- `Cmd+B` for **bold**
- `Cmd+I` for *italic*
- `Cmd+U` for underline
- `/` to open the slash command menu
