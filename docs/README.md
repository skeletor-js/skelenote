# Welcome to Skelenote

**Free. Encrypted. Yours.**

Skelenote is a local-first, zero-knowledge notes app. Your vault lives on your device, encrypted with keys only you control.

---

## Core Principles

- **Free** — Every feature, no subscriptions, no gates
- **Encrypted** — Your data is encrypted before it leaves your device
- **Portable** — Import from Notion, Obsidian, Markdown. Export the same way.
- **Offline** — Works without internet

---

## Key Features

| Feature | Description |
|---------|-------------|
| **Object Graph** | Everything connects—tasks, notes, projects, people |
| **Local Sync** | Sync devices on the same network |
| **Cloud Sync** | Encrypted sync across the internet |
| **Skeleton Key** | 24-word phrase only you control |
| **Rich Editor** | BlockNote with @mentions and backlinks |
| **Full Export** | Markdown, HTML, JSON, PDF |
| **Import** | Bring your data from Notion, Obsidian, or Markdown |
