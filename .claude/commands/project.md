View and manage the Skelenote Roadmap GitHub Project board.

## Quick Commands

- View project: `gh project view 1 --owner skeletor-js`
- List all items: `gh project item-list 1 --owner skeletor-js`
- List by milestone: `gh issue list --milestone "v0.2 - Exodus" --state open`
